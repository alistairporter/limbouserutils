# Limbo User Utils
Limbo plugin adding some user management features

**Requires at least Limbo version 0.7.12-ALPHA**

## Limbo
https://github.com/LOOHP/Limbo/

## Compilation
install maven and run `mvn verify` in this folder to produce the .JAR files

## Installation
1. Put **LimboUserUtils.jar** into your **Limbo server's** plugin folder!
2. Restart the Limbo server.
